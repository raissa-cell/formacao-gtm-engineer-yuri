# Mapa dos 7 módulos da formação

Ao fim dos 7 encontros, o motor da sua empresa está gerando leads. Cada módulo usa uma parte deste repositório: ver a coluna "Onde no repo" no `README.md`.

---

## Dia 01 · Fundamentos

**Documentação da aula:** [Aula 01 — Fundamentos, skills e loops](aulas/aula-01-fundamentos.md)

**Card:** ICP, Claude Code como sistema operacional e a estrutura do seu projeto.
**Modal:** A base de tudo

O que você vai aprender
- GTM Engineering na prática: a ponte entre estratégia comercial e execução técnica
- O processo de ponta a ponta que você vai construir nas próximas 4 semanas
- Como encontrar o seu ICP pelos sinais que indicam um cliente ideal
- Claude Code como sistema operacional único do seu projeto
- Estrutura de pastas do seu projeto, no padrão de produção

Entregáveis
- Conta no GitHub e o repositório da formação clonado, com commit e push
- Prompt de linha de base com o print do lead (Ex 01) e a versão com o Template Master (Ex 02)
- Seu `tom-de-voz.md` (Ex 03), aplicado junto com o `humanize-pt-br` (Ex 04)
- Sua skill `nota-de-conexao` (Ex 05), rodando em loop com 5 critérios (Ex 06)

Ferramentas: Claude Code
Skills: `humanize-pt-br` · `brand-voice-enforcement` · `grand-slam-offer-builder`

## Dia 07 · Dedicado a você

**Card:** Depois de construir a máquina, o último dia é sobre você.
