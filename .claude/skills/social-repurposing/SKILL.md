# Social Repurposing

## Purpose
Transform one piece of video content into platform-native social content.
Each platform has its own format, rhythm, and audience expectation.
Repurposing is not copy-pasting — it's a full rewrite for each platform's context.

## Core Rule
```
One idea. Six native executions.
Never copy-paste from script to post.
Each format must feel like it was born there.
```

---

## Input Detection

Adapt to whatever is available:

```
Level A — Richest:  Full script + title + hook + brand guidelines
Level B — Strong:   Full script + brand guidelines
Level C — Minimal:  Title + hook + core idea
Level D — Raw:      Transcript only (extract core idea + hook)
```

If brand guidelines not in context:
"Which channel/brand is this for? Voice and tone affect every format.
If Noiseless/Gunnar Greystone, just confirm."

## Recommendation Logic

When user says "recommend":

Score each platform on 3 dimensions for the given content:

```
Audience fit:    Does this topic resonate with this platform's audience?
Format fit:      Does the content structure translate well to this format?
Virality fit:    Does the emotional hook work in this platform's context?
```

Platform audience profiles:
```
LinkedIn:    Professionals, founders, operators. Pain = career/performance.
             Best for: case studies, lessons from failure, frameworks, counterintuitive takes.

X/Twitter:   Intellectually curious, opinion-driven, debate-ready.
             Best for: hot takes, myth-busts, lists, philosophical one-liners.

Instagram:   Visual-first, aspirational, identity-driven.
             Best for: identity hooks, transformation narratives, quote-driven content.

Threads:     Casual, conversational, close to X but warmer tone.
             Best for: personal observations, short takes, relatable moments.

Newsletter:  High-intent subscribers, deeper engagement tolerated.
             Best for: essay-style pieces, case studies, frameworks with depth.

Blog:        Search-intent, evergreen, SEO-driven.
             Best for: how-to, listicles, myth-busts, foundational concepts.
```

Output recommendation as:
```
Best fits for this content:
1. [Platform] — [one sentence why]
2. [Platform] — [one sentence why]
3. [Platform] — [one sentence why]

Which would you like me to write?
```

## Platform Formats

### A — LINKEDIN POST

**Audience:** Professionals, founders, operators
**Tone:** Direct, insightful, slightly personal. Authority without arrogance.
**Length:** 150–300 words optimal. Max 400.

**Structure:**
```
Line 1:  Hook — the strongest possible first line.
         Must create a pattern interrupt in the feed.
         No "I'm excited to share..." — ever.
         Max 8 words. Statement or provocative claim.

[blank line]

Lines 2–4: The tension or story. 2–3 short paragraphs.
           Each paragraph max 2 sentences.
           Blank line between each paragraph.

[blank line]

Lesson:  The insight or framework. 1–2 sentences.
         Most shareable line of the post.

[blank line]

CTA:     One question or one action. Never both.
         Designed to generate comments.
```

**Rules:**
- First 2 lines must work without expanding ("see more")
- No bullet lists in the hook — save for the body if needed
- No hashtags in body — 3 max at the very end if used
- Blank lines between every paragraph (LinkedIn algorithm rewards engagement time)

---

### B — X / TWITTER THREAD

**Audience:** Intellectually curious, debate-ready, fast scrollers
**Tone:** Sharp, opinionated, punchy. Each tweet standalone.
**Length:** 5–10 tweets. First tweet = hook. Last tweet = insight + follow CTA.

**Structure:**
```
Tweet 1 (Hook):
  The most provocative version of the central idea.
  Max 240 chars. Must work completely alone.
  End with "🧵" or "Thread:"

Tweet 2–3 (Setup):
  The problem or context. Short. Each tweet one idea.

Tweet 4–7 (The meat):
  The argument, list, or story. One point per tweet.
  Use numbering: "2/ The reason most people fail here..."

Tweet 8–9 (The turn):
  The counterintuitive insight. The best line.

Tweet 10 (Close):
  Summary in one sentence.
  Follow CTA: "Follow @[handle] for more on [topic]."
  Retweet ask if warranted: "RT if this reframed something."
```

**Rules:**
- Every tweet must work as a standalone post
- Never split a sentence across tweets
- Use numbers (1/, 2/) for clarity in long threads
- No emojis unless brand uses them — Noiseless: never

---

### C — INSTAGRAM CAPTION

**Audience:** Visual-first, aspirational, identity-driven
**Tone:** Personal, reflective, emotionally resonant. Slightly more vulnerable than LinkedIn.
**Length:** 150–220 words. After 3 lines, caption collapses — hook must be in first 3 lines.

**Structure:**
```
Lines 1–3 (Above fold):
  Hook — must stop the scroll after viewing the image.
  Often completes or extends what the image says.
  Never describes the image — adds meaning to it.

[blank line]

Body (2–3 short paragraphs):
  The insight, story, or lesson.
  More personal tone than LinkedIn.
  Speak to one person, not an audience.

[blank line]

Close:
  One declarative statement — the most quotable line.

[blank line]

CTA:
  One question designed for comments.
  Or: "Save this for when you need it."

[blank line — then hashtags as separate block]
#[tag1] #[tag2] #[tag3] ... (up to 10, niche + broad mix)
```

**Rules:**
- First 3 lines determine whether they tap "more"
- Never start with the creator's name or "I"
- Hashtags always in a separate block at end, never in body

---

### D — THREADS POST

**Audience:** Conversational, warm, closer to personal social than professional
**Tone:** Casual authority. Slightly more relaxed than X. Less formal than LinkedIn.
**Length:** 150–300 chars for single post. Up to 5 connected posts for thread format.

**Structure (single post):**
```
One idea. One take. One emotion.
No thread mechanics needed unless the idea genuinely requires it.
End with a question or an open statement that invites reply.
```

**Structure (thread — use when content has 3+ distinct points):**
```
Post 1: Hook — the most interesting version of the idea
Post 2–4: Supporting points, one per post
Post 5: The insight or lesson — the one people will screenshot
```

**Rules:**
- More conversational than X — contractions, first person OK
- Less polished than LinkedIn — raw observation > packaged insight
- If the idea fits in one post, use one post

---

### E — NEWSLETTER SNIPPET

**Audience:** High-intent subscribers who chose to receive this
**Tone:** Direct, intelligent, slightly more intimate. Longer form tolerated.
**Length:** 200–400 words. One section of a larger newsletter or standalone.

**Structure:**
```
Subject line suggestion: (if standalone send)
  [curiosity gap or specific promise — max 8 words]

Opening hook (1–2 sentences):
  Same logic as video hook — painful truth or dismantled assumption.

Context (2–3 sentences):
  Why this matters. Brief setup.

Core insight (3–5 sentences):
  The main idea, fully explained. More depth than social posts.
  Can include a specific example or data point.

Application (2–3 sentences):
  What the reader does differently because of this.
  Specific, not abstract.

Close (1 sentence):
  Declarative. The most memorable line of the section.

[Optional: link to full video]
  "Watch the full breakdown here: [LINK]"
```

**Rules:**
- No click-bait subject lines — subscribers already trusted you
- One idea per section — don't try to cover the whole video
- Always end with a clear takeaway, not a cliffhanger

---

### F — BLOG POST INTRO

**Audience:** Search-intent reader — found this via Google or link
**Tone:** Clear, authoritative, SEO-aware but human.
**Length:** 150–250 words. This is the intro only — not the full post.

**Structure:**
```
Paragraph 1 — Hook (2–3 sentences):
  Open with the central tension or a specific scenario.
  Primary keyword embedded naturally in first 100 words.
  No "In this article, I will..." — ever.

Paragraph 2 — The problem (2–3 sentences):
  Why most people get this wrong or why this matters.
  Secondary keyword embedded naturally.

Paragraph 3 — The promise (2–3 sentences):
  What the reader will understand by the end.
  Specific outcomes, not vague promises.
  Internal link opportunity: "If you haven't read [X], start there."

[Transition to Section 1 of article]
  "Let's start with [first main point]."
```

**Rules:**
- Primary keyword in first paragraph — for SEO
- No header for intro — just flows directly into body
- Must create enough tension to scroll past the fold

## Noiseless Voice Rules (apply when brand = Noiseless)
- No "Hey" openers, no greetings, no "I'm excited to share"
- No hyperbole (incredible, life-changing, game changer)
- First line always a statement — never a question
- Anglo-Saxon vocabulary preferred
- Gunnar voice: calm, precise, contrarian, intellectually peer-level
- Instagram/Threads: slightly warmer but never loses the stillness
- LinkedIn: full Gunnar authority — intellectual peer, not teacher
- X/Twitter: sharpest version of the idea — compressed to the bone
- Newsletter: most depth — the format Gunnar would choose if forced to write
