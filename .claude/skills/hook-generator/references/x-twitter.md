# Surface: X / Twitter

ALSO read `references/text-style-rules.md` before generating.

## Cut point (D1 Fold Survival)
The hook is the **first tweet** of a thread, or the **entire** single post. It must
read as a complete, standalone sentence — no "a thread 🧵👇" crutch, no "as I'll explain."
280-char hard limit per post. The first ~125 chars carry the stop.

## Weights for scoring
D1 0.30 · D2 0.25 · D3 0.15 · D4 0.30
(Shareability is the highest weight of any surface: the quote-tweet / repost is THE
growth loop on X. A hook that invites a quote-tweet reply outperforms a closed one.)

## Length / structure
- Single post: ≤280 chars, every word earns its place. One idea.
- Thread: post 1 = hook (standalone), creates pull to post 2. Number threads 1/N.
- Hook + optional rehook must fit 280 together; if not, drop the rehook.
- Register is rawer than LinkedIn. More edge, contractions fine, same confidence.

## Surface mechanics for D4 (Shareability / Stake)
Quote-tweet bait beats applause bait. A hook stating a position people want to argue
WITH (or signal-boost) wins. Mild controversy and strong specificity both drive quotes.

## Types that over-index
Arresting Claim/Bold, Contrarian/Myth-Bust, Statistic/Number, Identity Threat.

## Worked examples
